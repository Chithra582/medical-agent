# Pharmacology & ADMET Analysis

## Overview
This skill computes absorption, distribution, metabolism, excretion, and toxicity profiles for small molecule candidate compounds.

## Capabilities
- Parses chemical SMILES representations and verifies molecular valence sanity.
- Calculates physicochemical descriptors (MW, LogP, TPSA, HBD, HBA) and Lipinski compliance.
- Predicts cytochrome P450 inhibition, hERG liability, and cellular toxicity risks.
