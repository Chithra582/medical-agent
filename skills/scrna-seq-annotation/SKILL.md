# Single-Cell RNA-Seq Annotation

## Overview
This skill processes single-cell transcriptomic profiles, performs marker gene identification, and maps clusters to canonical cell types.

## Capabilities
- Interprets differential gene expression rankings and calculates log2 fold changes.
- Maps top marker signatures against reference cell atlases (Human Cell Atlas, CellMarker).
- Formulates functional cell state hypotheses across immunological and oncology samples.
