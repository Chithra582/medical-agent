# CRISPR Screen Planning

## Overview
This skill designs experimental CRISPR knockout, interference, and activation screens for target gene sets.

## Capabilities
- Generates high-efficiency single guide RNA (sgRNA) candidates for specific genomic loci.
- Evaluates on-target cleavage efficiency and flags predicted off-target genomic cleavage sites.
- Formulates multi-well plate layout matrices and positive/negative control configurations.
